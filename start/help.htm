TIF File not shown - but a big Q ?

If you open a TIF File and there is only a big blue Q character in the middle of your browser instead of a drawing,
you have to customize your "Quick Time" Installation.
Siemens Energy users contact the Service Desk for customizing
Necessary customizing:
Remove TIFF setting under Edit_Preferences_Quick Time Settings_Browser Plug-in\ MIME Settings \ Images

 

Associate File Types with an other Viewer Program

If you want to associate a file type (e.g. *.dgn) opening with a special program (e.g. AIM Redline) you have to do:

  • open windows explorer and find a file of this file type
  • select the file by mouseclick
  • press the Shift key and right mouseclick together. A new window appears:
  • click "open with" and choose the special program.

You will find the special path of a viewer programs in the next chapter "Recommendation for SIGMA viewer programs"

Search Function

General:

    The search is not case sensitiv !
    The search fields are combined with logical 'AND'.
    It is not possible to search for empty file folders, tab sheets or directories. (empty = structures without documents)
    If a document is in a directory the directory name will be shown in the "Folder description" column.

Using Wildcards

  • ? for one character
    example: U?? = finds UBA and UBB but not UC or UBA10 

Logical search in field TITLE with "AND"

example: gas and turbine = find "gas turbine area"
